# Maps

Forge map variants (`.mvar`) and maps saved from the Project Reclaimer map
editor (`.json`). Add one by pull request. A playlist names one as
`"Maps/<file>"` or by the name stored inside it.

A saved map that places objects from another map needs that map in the
server's `game/` folder, and one that uses objects from a mod needs that mod
listed in `mods.json`.
